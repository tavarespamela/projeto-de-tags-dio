Usando tags HTML para personalizar sua página

No HTML existe uma infinidade de tags que podem ser usadas para personalizar sua página. Desde tamanhos diferentes para as escritas, até cores diferentes, listas, fontes e muito mais.

Mas antes de tudo, o que são tags em HTML?

As tags em HTML são marcações que informam ao navegador como a estrutura de uma página deve ser organizada e exibida. Elas são comandos usados para definir elementos, como títulos, parágrafos, imagens, links e muito mais. Cada tag tem uma função específica e é representada por um nome entre colchetes angulares (< >).
Já pensou em usar uma fonte grandona ou pequenininha para estilizar seu texto? No HTML existe uma infinidade de tags que podem ser usadas para personalizar sua página. Então vamos lá!

Tags de cabeçalho

Tags de cabeçalho são usadas para criar títulos e subtítulos em uma página web. Elas variam de <h1> a <h6>, sendo <h1> o nível mais alto e <h6> o nível mais baixo.

<h1> → cabeçalho nível 1

<h2> → cabeçalho nível 2

<h3> → cabeçalho nível 3

<h4> → cabeçalho nível 4

<h5> → cabeçalho nível 5
<h6> → cabeçalho nível 6

Tags de estruturação

As tags de estruturação ajudam a organizar o conteúdo da página, tornando o HTML mais legível para navegadores, mecanismos de busca e tecnologias de acessibilidade.

<div> → Agrupa e organiza elementos.
<hr> → Cria uma linha horizontal para separar seções.
<span> → Aplica estilos a partes específicas do texto.

Tags de personalização de texto

As tags de personalização de texto permitem alterar a aparência do conteúdo em uma página web.

<b> → Negrito*
<strong> → Destaque*
<i> → Italico
<u> → Sublinhado
<p> →

cria parágrafos.


<mark> → destaca texto.
<small> → reduz o tamanho do texto.
<del> → marca conteúdo removido.
<abbr> → define abreviações.

*A tag <strong> é utilizada para indicar que um texto possui forte importância. Embora geralmente seja exibida em negrito, seu objetivo principal é dar significado semântico ao conteúdo.
Já a tag <b> é utilizada apenas para aplicar negrito visual ao texto, sem indicar importância.

Como mudar as cores do texto?

No HTML moderno, as cores são aplicadas utilizando CSS através do atributo style.

<p style="color: blue;"> → texto azul
<p style="background-color: yellow;"> → texto com fundo amarelo
<p style="text-align: center;"> → texto centralizado
<p style="font-size: 24px;"> → texto com tamanho de fonte 24px

Criando uma lista

As vezes queremos organizar as informações em formato de lista, seja ela ordenada ou não. Então o html oferece opções para isso.

<ol> → Cria listas ordenadas (numeradas).
  1. uma
  2. lista
  3. ordenada ou
  4. numerada
<ul> → Cria listas não ordenadas (com marcadores).
  • uma
  • lista
  • não
  • ordenada
  • com marcadores
<li> → Define um item da lista. Ou seja, ele não forma uma lista sozinho, mas sim dentro de uma lista ordenada ou não ordenada. Então para criar uma lista, você precisa usar a tag <li> dentro de uma tag <ol> ou <ul> dessa forma:

<ol> → Cria uma lista ordenada (numerada).
<li>uma</li> → sinaliza um item dessa lista
<li>lista</li> → sinaliza um item dessa lista
<li>ordenada ou</li> → sinaliza um item dessa lista
<li>numerada</li> → sinaliza um item dessa lista
</ol> → finaliza a lista ordenada (numerada).

Tags de especiais

Algumas tags são usadas para indicar informações especiais, como citações, códigos, links e imagens. Elas ajudam a estruturar o conteúdo de forma mais clara e semântica.

<a> → Cria hiperlinks. Como os que usamos no índice para navegar entre as seções da página ou nos botões de voltar.
<sub>→ Exibe texto subscrito.
<sup>→ Exibe texto sobrescrito.
<blockquote>→
uma citação em bloco.
